- 雄安新区：9 条；
- APEC 2026：9 条；
- 习近平海外活动：9 条。

每条记录保留 `original_url`、`published_at`、快照 `collected_at`、平台/来源、语言、地区、采集方式和访问状态。只保存标题与短摘要，不复制受版权保护的全文。页面中的原文按钮始终指向来源站点。

2026-08-28 随包快照共有 28 条记录，专题分布为 9 / 9 / 10。最近一次采集对 12 个渠道完成一轮访问，8 个入口公开可读，4 个受限或失败；当轮检查 257 条候选元数据，没有新增专题命中，因此保留此前已核验记录且不制造新增数据。该数字会随下一次公开源刷新变化。

## 运行方式

首次部署或需要刷新时，在项目根目录依次执行：

```bash
python scripts/collect_public_web.py --timeout 18 --limit 24
python scripts/import_public_demo.py --db backend/data/opinion_monitor.db
```

兼容入口 `python scripts/collect_public_demo.py` 调用同一个采集实现。采集器仅发匿名 GET，请求体上限 3 MiB；检测到登录、验证码、订阅或访问控制标记后停止解析。输出先写临时文件再原子替换，已有记录按 URL 去重；`web-*` 自动记录会在刷新时重新执行专题规则，不再匹配的误命中会被剔除。为保留历史证据，内容离开 RSS 最近条目列表时不会自动删除；来源撤回与保留期清理须走独立审核流程。导入同样幂等。服务启动不会自动采集，以便部署方明确控制联网时间窗。API 提供：

- `GET /api/public-demo/status`：样本批次、采集运行、12 渠道状态、平台和采集时间；
- `GET /api/public-demo/topics`：三个专题聚合；
- `GET /api/public-demo/topics/{slug}`：专题指标、国家/平台分布和记录；
- `POST /api/public-demo/refresh`：核心课题组重新导入快照。

专题记录可从指标、关键词、国家/平台和列表逐层打开统一证据抽屉，查看原文、中文翻译配置状态、发布时间、采集时间、关键词、情感/立场/风险状态、互动元数据和原始链接。当前情感、立场、翻译字段明确显示“未运行/待配置”，不将规则或摘要伪装成模型结论。

## 与需求优先级的对应

- P0：重点专题入口、三专题、自由关键词检索、专题聚合、记录详情、原始来源下钻、更新时间和演示标签；
- P1：国家/媒体分布、专题事件视图、证据引用、报告/检索链路；
- P2：正式平台 API、实时调度、通知、统一身份、OCR/ASR/翻译和移动端仍由授权与部署条件决定。

上线前应为正式连接器补充凭据托管、限流/重试、站点条款审查、数据保留策略、TLS、统一身份和恢复演练。任何需要登录、验证码、付费墙或访问控制的页面都不通过绕过方式采集。
