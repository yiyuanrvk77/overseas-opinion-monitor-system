# 需求交付分析与上线边界

## 结论

《社科院海外监测系统需求优先级.xlsx》的 32 项产品需求已全部进入数据库需求矩阵和可查询接口，不删除、不合并采购条目以外的产品要求。当前工程状态为：8 项已实现、17 项部分实现、7 项已搭建扩展位。

“部分实现”与“已搭建扩展位”不是失败状态，而是明确区分当前代码能力与必须由正式授权、模型评测或生产基础设施才能完成的能力。页面和报告不得把这些状态包装为已经接通。

## 本轮可验收能力

| 范围 | 可验收结果 | 证据 |
| --- | --- | --- |
| 12 渠道 | 六个社媒、六个媒体固定登记并执行公开可达性巡检 | 采集运行摘要、每渠道 HTTP/访问状态、来源 URL |
| 真实公开数据 | 公开 RSS、Atom、HTML 标题和短摘要进入统一批次 | `data/public_demo_data.json`、快照 SHA-256、内容哈希 |
| 三个专题 | 雄安新区、APEC 2026、习近平海外活动独立聚合 | 专题列表、平台/国家分布、记录详情 |
| 检索与问答 | 当前活动批次的混合检索、拒答和逐条引用 | 记录 ID、来源链接、证据类型、内容哈希 |
| 图谱与报告 | 当前活动批次建图并生成结构化报告 | 批次号、报告引用、审计链 |
| 数据治理 | 显式活动批次、幂等导入、原子快照、索引一致性 | `workspace_setting`、采集运行信息、自动化测试 |
| 部署 | 前后端构建产物、Linux 启动脚本、systemd/nginx 说明 | `dist/`、`start.sh`、`deploy/` |

## 仍需外部条件的需求

| 外部条件 | 影响范围 | 当前产品行为 |
| --- | --- | --- |
| 平台或供应商正式接口 | 社交帖子、评论、互动量、完整三个月回溯、持续调度 | 公开可读部分入库；受限渠道记录原因，正式连接器保持待配置 |
| OCR、ASR、翻译服务 | 图片、视频和多语种内容理解 | 保存媒体/语言任务契约，结果字段保持待配置 |
| 经评测的分类与生成模型 | 情感、立场、风险、趋势、自动报告 | 不生成虚构比例或结论；只展示来源标签和结构化摘要 |
| 统一身份与组织目录 | 最高敏感层实名授权 | 支持环境变量启用服务端认证；正式环境仍应接 IAM/SSO |
| 生产数据基础设施 | 多实例、高并发、队列、对象存储、集中监控 | 当前支持单机 SQLite/WAL、日志、备份与健康检查 |

## 上线判定

本版本可以作为单机试运行产品部署，用于展示公开数据进入采集、批次、专题、检索、知识、图谱、报告和审计闭环。它不能被表述为“12 个平台正式接口均已采购接通”，也不能将公开主页探测等同于帖子采集。供应商接口到位后，应沿现有统一记录契约新增适配器，而不是改写业务页面。

## 验收入口

- `/api/health`：数据库、索引、审计链和运行状态；
- `/api/public-demo/status`：公开快照、采集运行和 12 渠道状态；
- `/api/public-demo/topics`：三个专题及平台/地区分布；
- `/api/requirements`：32 项需求的实现状态、验证方式和剩余条件；
- `/api/collection`：正式连接器注册、任务草稿和批次管道；
- `/api/audit/verify`：哈希审计链校验。
